# bootcamp：7 天把手感练回来

这个文件夹是给你**动手**用的，不是给你看的。

## 怎么用

1. 打开 PyCharm，把这个 `bootcamp` 文件夹作为项目打开（不要打开整个 `D:\python\project`，太乱）。
2. 从 `day01_wordcount.py` 开始，按文件里的 TODO 顺序填空。
3. 每填一个 TODO，就运行一次。**跑不通是正常的，跑通才是意外。**
4. 卡住超过 30 分钟，再去看 `从零到项目_手把手.md` 里对应的参考答案。

## 每天的验收标准（自己打勾）

- [√ ] Day 1：`python day01_wordcount.py` 能打印出词频前 10
- [√ ] Day 2：能接受命令行参数 `python day01_wordcount.py sample.txt 20`
- [√ ] Day 3：能写出 `wordcount.log`，里面有 INFO 和 ERROR
- [ ] Day 4：`git log` 能看到 3 次提交
- [ ] Day 5：`pytest` 能跑过 3 个用例
- [ ] Day 6–7：命令行单词本能 add / list / search / delete

## 三条规矩

1. **不许让 AI 生成整个文件。** 只能让它解释报错、review 你写的 20 行。
2. **每段 AI 给的代码，删掉一行再跑一次。** 看它怎么坏的，你就懂它为什么这么写了。
3. **每天结束时在 `journal.md` 写三行**：今天写了什么 / 卡在哪 / 明天第一件事。
